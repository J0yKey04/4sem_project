# 4sem_project
Добро пожаловать на страницу проекта rainbow simulation!

Наша программа позволяет визуализировать прохождение лучей через каплю воды при помощи разных моделей - геометрической оптики, волновой оптитки в модели Ми и модели ... . Симуляция показывает как ведут себя лучи в капле воды и демонстрирует образование радуги. 

В интерефейсе есть возможность выбрать модель, передвинуть источник и каплю.
